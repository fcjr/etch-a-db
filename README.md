# etch-a-db

An etch-a-sketch with a sql-like syntax for writing and reading memory.

## Description

Built for https://fliptable.nyc.  Eventually it will be a physical etch-a-sketch.  We use OCR for SELECT so it can be applied to the real one, which makes reading.... kinda bad :)

- React Three Fiber
- Koota
- Tesseract.js
- Cloudflare Workers
